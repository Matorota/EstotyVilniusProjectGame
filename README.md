# Ork slayer

A Unity mobile action RPG.

## Game Premise

You play as a guild hero in a world overrun by ork forces. Battle through levels, complete quests, and defeat waves of enemies to progress. Along the way, collect loot, unlock ability cards, and upgrade your gear to survive tougher challenges. Each level is a test of both strategy and reflexes: knowing when to attack, defend, or use an ability is key. More to be added in the future!
## How to Play

- **Move:** use the on-screen virtual joystick.
- **Attack:** tap the action button to hit nearby enemies.
- **Defend/Ability:** use the guard and ability buttons to survive tough fights.
- **Quests:** clear each level's objectives to unlock the next.
- **Upgrades:** manage abilities, cards, and guild options from the in-game menus.

## Launch on Phone (APK)

### Easy install
1. Build the Android APK in Unity: **File → Build Settings → Android → Build**.
2. On the phone, enable **Install unknown apps** for your file manager/browser.
3. Copy the `.apk` to the phone (USB, cloud, or SD card).
4. Open the file and tap **Install**.
5. Launch the game from the home screen.
